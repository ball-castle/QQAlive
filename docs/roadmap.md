# 路线与验收

## V0：先验证链路

1. 在 QQ 开放平台注册或绑定机器人，建立可管理的测试群，确认私聊和群聊权限。
2. 按 [官方插件说明](https://github.com/tencent-connect/dsh-qqbot)安装 DeepSeek Harness 与 `@tencent-connect/dsh-qqbot`，按当前说明完成绑定。
3. 检查 [第三方 Codex 订阅插件](https://github.com/WSL043/dsh-codex-subscription) 的源码、授权方式、兼容版本和相关服务条款，再决定是否安装。账号授权和可用模型以实际服务为准。
4. 在隔离环境测试，确保群成员不能触发 shell、文件修改或其他高风险工具；不要假定默认配置已经安全。
5. 测试私聊、多轮上下文及测试群 @ 回复，记录故障和配置。凭据、聊天记录和个人信息不得提交到公开仓库。

### 验收清单

- [ ] 官方 QQ 机器人绑定成功
- [ ] QQ 私聊可调用目标 Codex 模型
- [ ] 测试群 @机器人可回复
- [ ] 连续对话保留正确上下文，且不同会话隔离
- [ ] 实际确认群全量消息读取权限与主动发送规则，分别记录结果
- [ ] 验证普通群成员无法使用高风险电脑操作

所有项目目前均未验证。群聊全量消息与主动发言是不同能力，取决于平台规则、账号和群配置；V0 只以响应 @ 为目标。

## V1：独立 Agent 系统

计划将 QQ 通道、模型路由、会话与记忆、社交决策、TTS、音乐和图片生成拆成可替换模块。先验证平台权限，再决定社交引擎的触发和主动发言方式。记忆应有明确的保存、删除和访问控制策略；语音的编码与发送要求以腾讯当前文档和实测为准。

建议顺序：官方 SDK 收发 → 模型与会话隔离 → 社交决策与记忆 → 语音、图像和音乐。每一步都需独立验证；具体实现和依赖尚未确定。
